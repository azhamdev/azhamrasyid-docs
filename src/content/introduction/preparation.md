# Persiapan

Sebelum memulai, ada beberapa hal yang perlu Anda siapkan terlebih dahulu. Halaman ini merangkum semua kebutuhan awal agar lingkungan pengembangan Anda siap untuk mengikuti materi berikutnya.

## Software & Tools yang Perlu Diinstal

- **Node.js (LTS Version)** — Runtimes JavaScript untuk menjalankan tools dan dependensi modern.
  - Download: [Node.js Official Website](https://nodejs.org/)
- **Python 3.11+** — Diperlukan untuk pengembangan backend, skrip AI, dan framework FastAPI.
  - Download: [Python Official Website](https://www.python.org/downloads/)
- **Visual Studio Code** — Code editor utama untuk pengembangan proyek.
  - Download: [Visual Studio Code](https://code.visualstudio.com/)
- **Git** — Version control system untuk mengelola repositori dan kode program.
  - Download: [Git SCM](https://git-scm.com/downloads)
- **Postman / Bruno** — API Client untuk menguji endpoint RESTful API atau API streaming.
  - Download Postman: [Postman Download](https://www.postman.com/downloads/)
  - Download Bruno: [Bruno Official Website](https://www.usebruno.com/)

## Langkah Persiapan

Ikuti langkah-langkah berikut secara berurutan:

1. **Unduh dan Instal Software** — Unduh semua software yang tertera di atas sesuai dengan sistem operasi yang Anda gunakan (Windows, macOS, atau Linux).
2. **Konfirmasi Instalasi via Terminal** — Buka Terminal / Command Prompt, lalu jalankan perintah berikut untuk memastikan instalasi berhasil:
   - `node -v`
   - `python --version`
   - `git --version`
3. **Instal Ekstensi VS Code** — Buka VS Code dan pasang beberapa ekstensi pendukung seperti **Python**, **Pylance**, **Prettier**, dan **GitLens**.

## Memeriksa Kesiapan

Pastikan semua poin di bawah ini sudah terpenuhi sebelum melanjutkan:

- [ ] Node.js dan Python sudah terinstal dan terdeteksi di Terminal/Command Line.
- [ ] Git sudah dikonfigurasi dengan username dan email Anda.
- [ ] VS Code sudah dapat digunakan dan ekstensi pendukung telah terpasang.
- [ ] API Client (Postman/Bruno) siap digunakan untuk pengujian API.

> **Catatan:** Jika mengalami kendala saat proses instalasi atau konfigurasi, Anda dapat melihat halaman [Tentang Saya](/about-me) atau menghubungi saya untuk bantuan lebih lanjut.

Setelah semua persiapan selesai, Anda siap untuk melanjutkan ke langkah berikutnya. Selamat belajar!
