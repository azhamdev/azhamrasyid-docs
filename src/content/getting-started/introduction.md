# Introduction

Welcome to **Frontend Foundations** — a hands-on guide to building things for the web, written for people who learn by doing. No prior experience is assumed. By the end you'll be able to read a webpage's source, understand what each part does, and write your own.

This isn't a reference manual you skim once. It's a path. Each page builds on the one before it, and every concept comes with something you can type out and run yourself.

![A minimal wireframe of a documentation layout: navigation on the left, content in the middle, page outline on the right.](https://placehold.co/1200x600/0a0a0a/ffffff/png?text=Frontend+Foundations)

## What you'll build

Along the way you'll go from a blank file to a small, interactive interface — the same core skills behind every website you use. Concretely, you'll learn to:

- Structure content with **HTML** so browsers and screen readers understand it.
- Style that content with **CSS**, from colors to full responsive layouts.
- Add behavior with **JavaScript** — responding to clicks, input, and change.
- Think in **components**: small, reusable pieces that make up a real UI.

## Who this is for

You'll feel at home here if you're a student, a career-switcher, or simply curious about how the sites you use every day are made. If you can open a text editor and a browser, you have everything you need to start.

> You don't need a computer science degree, expensive software, or a fast machine. You need a browser and a willingness to try things and break them.
