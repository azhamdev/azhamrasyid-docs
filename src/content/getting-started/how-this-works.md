# How This Guide Works

A few conventions repeat on every page. Knowing them up front means you can focus on the ideas instead of the formatting.

## Reading the layout

The screen is split into three parts, and each has a job:

| Region | What it's for |
| --- | --- |
| Left sidebar | The full course, grouped into chapters. Your current page is highlighted. |
| Center column | The page you're reading. |
| Right column | The outline of *this* page. It tracks your scroll position. |

At the bottom of every page, the **Previous** and **Next** buttons move you one step along the path — so you can read straight through without touching the sidebar.

## Code blocks

Code you can run appears in a monospaced block. Read it, then type it out yourself — copying by hand is slower, and that's the point. It's how the syntax sticks.

```js
// A greeting, printed to the browser's console.
const name = 'world';
console.log(`Hello, ${name}!`);
```

Short snippets appear `inline` when they're part of a sentence — a tag name, a value, a keyword.
